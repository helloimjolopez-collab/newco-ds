On the shadow: a shadow behind the page is a layout/presentation choice, not part of the surface color token — the Sheet token only carries a fill. That is why Figma (flat) and the demo (shadowed) will not match 100% on depth even when the color is identical. If you want the shadow baked into the pattern I can wire the page container to the --elevation-* scale, but the token value itself stays a flat color.
