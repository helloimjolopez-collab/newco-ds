# Token Architecture & Economy

A quick, complete mental model — readable by any developer or AI agent.

## Two layers

1. **Primitives** — `--primitive-color-{family}-{step}` (e.g. `--primitive-color-brand-600`).
   The raw palette: Brand ramp, Warm/Cool neutrals, status hues, accents, and the
   Midnight canvas set. **Don't consume these directly.**
2. **Semantics** — `--semantic-color-{category}-{role}-{variant}`
   (e.g. `--semantic-color-fill-surface-elevated-sheet`). One name per token, no mode
   in the name. Role-based, **references** a primitive via `var()`. **Build with these.**

```
--primitive-color-warm-neutral-75:            #f1eaea;                       /* raw */
--semantic-color-fill-action-secondary-rest:  var(--primitive-color-warm-neutral-75);  /* one name; value set per theme */
```

Change a primitive → every semantic that references it moves with it. The alias
chain from Figma is preserved end-to-end.

## Modes

Two modes ship: **Light** and **Midnight**. Each semantic is **one name** whose
value is chosen by a `data-theme` selector, not by the name. Light values live in
`themes/light.css` (`:root, [data-theme="light"]`); the same names carry Midnight
values in `themes/midnight.css` (`[data-theme="midnight"], [data-theme="dark"]`).
Flip the page by setting `data-theme` on `<html>`, or a subtree by setting it on any
element — it composes both ways. Colour and the four `--elevation-*` shadows flip
together.

## Categories (semantic)

`foreground` (text + icon, unified) · `fill` (incl. surfaces under `fill-surface-*`)
· `stroke` · `scrim` — each split by role (Action / Static) and status family
(info, positive, negative, danger, warning, accents). Browse them under
**Tokens → Semantics**.

## The pipeline (Figma is the source of truth)

There is no Figma REST sync (the org is not on Enterprise). The Variables panel is
read via the Figma plugin / Dev-Mode (MCP) into the seeds under
`tokens/figma-source/`, then:

```
tokens/figma-source/*.json  --build-token-source-->  newco-design-tokens.json (DTCG)
   --Style Dictionary + stamp-headers + build-index-->  primitives.css · themes/{light,midnight}.css
     · layout.css · layout-contextual.css · type.css · motion.css · breakpoints.css · index.css
   --build-dist + build-contract-->  npm/ (+ README.md, contract.json)
   --build-nuget-->  nuget/ (concatenated newco-tokens.css + C# constants)
   --> npm publish  +  NuGet publish  (lockstep)
```

No manual export, no file watcher. See **Adoption** for install, and the repo's
`docs/governance.md` for versioning, ownership, and security.

## Token economy

Is the token count "too many"? It's the right **coverage**, with a leaner
**representation** available:

- The emitted CSS-variable count ≈ **primitives + semantics × 2 modes**. The ×2 is
  an encoding artifact (Light + Midnight as separate names), not extra decisions —
  a `[data-theme]` alias layer roughly halves it.
- **Consumers touch semantics only**; primitives are private.
- Primitive bulk is largely **alpha variants**; generating those with `color-mix()`
  trims ~30–40% with zero loss.
- Judge health by **coverage · no dead tokens · one-obvious-choice**, not raw count.
