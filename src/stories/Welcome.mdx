# NewCo (Spired) Design System — Tokens

The single source of truth for NewCo's visual language, delivered as versioned
packages. **Every value here is a 1:1 reflection of the Figma variable library**
(the Spired branch), pulled programmatically — never hand-maintained.

**Live Storybook:** https://helloimjolopez-collab.github.io/newco-ds/
**Repository:** https://github.com/helloimjolopez-collab/newco-ds

---

## What am I looking at?

This Storybook is the browsable face of the `newco-tokens` package. In the
sidebar:

- **Tokens → Colors** — the live palette rendered straight from the built
  `tokens.css`: the surface elevation stack (Light + Midnight), the Spired brand
  ramp, and a sampler of semantic roles.
- **Architecture** — how Figma → repo → packages fits together.
- **Adoption** — how any tribe (incl. Blazor/Radzen) installs and consumes it.

Components (starting with **Button**, as Lit Web Components) land under a
**Library** section in a later pass.

## Install

**npm** (React, Vue, Angular, Svelte, plain web, Tailwind):

```bash
npm install @helloimjolopez-newco/newco-tokens
```
```css
@import "@helloimjolopez-newco/newco-tokens/css";
.card { background: var(--semantic-color-light-mode-surface-widget-base); }
```

**NuGet** (Blazor / Radzen):

```bash
dotnet add package NewCo.Tokens
```
```html
<link rel="stylesheet" href="_content/NewCo.Tokens/newco-tokens.css" />
```

Both packages are built from the same source and released **in lockstep**.

## Token architecture

Two layers, mirroring Figma exactly:

1. **Primitives** (`--primitive-color-*`) — the raw palette (Brand ramp, Warm/Cool
   Neutrals, status hues, Midnight canvas set). ~417 values. Apps rarely touch
   these directly.
2. **Semantics** (`--semantic-color-{mode}-*`) — role-based tokens (surface, text,
   fill, stroke, icon × primary/info/positive/negative/…) that **reference**
   primitives via `var()`. ~490 roles, in **Light** and **Midnight** modes.

```
--primitive-color-warm-neutral-100:            #fcf9f9;
--semantic-color-light-mode-surface-sheet-base: var(--primitive-color-warm-neutral-100);
--semantic-color-midnight-mode-surface-sheet-base: var(--primitive-color-midnight-sheet);
```

The alias chain from Figma is preserved in the output — change a primitive and
every semantic that references it moves with it. **Consume semantics, not
primitives.**

See the repo `README.md`, `docs/adoption.md`, and `docs/governance.md` for the
full pipeline, versioning, ownership, and security posture.
